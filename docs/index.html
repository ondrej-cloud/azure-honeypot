How to read this

  • Connections are TCP sessions to the emulated SSH (port 22) or Telnet (23) service. No real system is exposed: every shell, file and command output is simulated by Cowrie.
  • Countries and networks come from iptoasn.com and describe where an IP is registered. Most sources are compromised machines, cloud VMs and proxies, not the people behind them.
  • ATT&CK techniques are matched heuristically from the commands typed into the fake shell (MITRE ATT&CK®).
  • All times are UTC. Data refreshes every 6 hours. Malware URLs are defanged on purpose; hashes link to VirusTotal.
